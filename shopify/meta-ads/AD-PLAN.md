# Meta ad plan: ₹2,000 for 15 days (12–26 Oct 2026)

## Setup in Ads Manager
- **Campaign**
  - Objective: **Sales**, if the Facebook & Instagram app is installed in Shopify with the Pixel on. If it isn't, use **Traffic** with "Landing page views".
  - Budget: **lifetime budget ₹2,000** (about ₹133 a day).
  - Schedule: **12 Oct to 26 Oct**.
- **One ad set**
  - Location: India.
  - Age: 24–50. Gender: Women.
  - Languages: English, Hindi, Gujarati.
  - Audience: Advantage+ audience, with these interests as suggestions: Kurti, Chikankari, Ethnic wear, Handloom, Block printing, Fabindia, Jaypore, Biba.
  - Placements: Advantage+ (Feed, Stories and Reels on Facebook and Instagram).
- **Four ads** in the same ad set. Meta automatically spends more on the ad that works best.
- **Day 6:** pause the ad with the lowest CTR or the highest cost per landing-page view. Don't change anything else, because edits restart Meta's learning phase.

Add this to every link, so you can see ad visitors in Shopify Analytics:
`?utm_source=meta&utm_medium=paid&utm_campaign=festive_oct26`
